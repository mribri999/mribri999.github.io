Direct Control Mode

Direct control of the spins is useful for quick demonstrations and teaching — no pulse sequence required.

Open it with Direct Control View on the welcome screen, or switch the spin control mode with the Mode button below the playback controls in the expanded Spins view (also available in Settings → Spin Control Mode). Direct Spin Controls act on every spin in the vector array at once.

Sliders

ControlEffect
ThetaElevation angle of all vectors (degrees).
PhiAzimuth angle of all vectors (degrees).
kx, ky, kzSpatially dependent phase, in cycles per FOV — wind the spins into a k-space pattern along each axis.

Changing theta is not the same as an RF rotation when the transverse spin phases differ.

Buttons

ButtonEffect
M0Resets all spins to the z axis.
T1Applies T1 relaxation for a time of T1/10.
T2Applies T2 relaxation for a time of T2/10.
Δf(r)Simulates spatially varying “static” off-resonance. Each press adds repeatable dephasing.
DSimulates random diffusive motion. Like Δf(r), but different with each press and not refocusable.
180xApplies a 180° pulse about x. It negates all k-space, supplements theta and flips phi, as well as any phase accrued from Δf(r) or D.

Try it: a spin echo

  1. Press M0, then set theta to 90° to tip the spins into the transverse plane.
  2. Press Δf(r) a few times — the spins dephase.
  3. Press 180x.
  4. Press Δf(r) the same number of times — the spins refocus into a spin echo.

Repeat with D presses mixed in to see how diffusion causes signal loss that the 180° pulse cannot recover.
